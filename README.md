# Agenda

Aplicacion movil personal para gestionar agenda, tareas y organizacion diaria.

## Estado del proyecto

Proyecto en fase inicial. Antes de definir la implementacion se decidiran:

- Stack tecnologico.
- Funcionalidades principales.
- Estructura de carpetas.
- Reglas de trabajo y documentacion.

## Flujo de trabajo con Codex

Codex solo modificara codigo o archivos cuando el usuario escriba explicitamente:

```text
PROGRAMALO
```

Comandos de trabajo acordados:

- `PLANEA`: pensar arquitectura, diseno o alternativas sin modificar archivos.
- `ANALIZA`: revisar el proyecto sin modificar archivos.
- `PROGRAMALO`: implementar cambios en archivos.

## Control de versiones

Este proyecto usa Git y se subira a GitHub como repositorio remoto.
